# Tema Uno Roto

Tema de bloques para la web de Uno Roto: de noche, neón violeta y ámbar, con las tipografías del juego (Roboto, Apache 2.0; Cormorant Garamond, SIL OFL 1.1) empaquetadas en `assets/fonts`. No hace ninguna petición a terceros.

- La página del juego lleva el shortcode `[uno_roto]` (plugin Nuevo Ser Core) y la plantilla **Página del juego (sin título)**, que deja la portada a todo el ancho.
- La cabecera enlaza a `/jugar/`; si la página tiene otro slug, se cambia desde el editor del sitio.
- Instalación local: enlace simbólico de esta carpeta en `wp-content/themes/uno-roto` y activar.
