# Tema Uno Roto

Tema de bloques para la web de los juegos de la Colección (nació con Uno Roto): de noche, neón violeta y ámbar, con las tipografías del juego (Roboto, Apache 2.0; Cormorant Garamond, SIL OFL 1.1) empaquetadas en `assets/fonts`. No hace ninguna petición a terceros.

- La página del juego lleva el shortcode `[uno_roto]` (plugin Nuevo Ser Core) y la plantilla **Página del juego (sin título)**, que deja la portada a todo el ancho.
- La cabecera lleva el menú de juegos (bloque Navegación nativo): Uno Roto en `/jugar/` y Las Versiones en `/las-versiones/` (shortcode `[las_versiones]`, misma plantilla). Se edita desde el editor del sitio (Apariencia → Editor → Navegación); el juego de la página actual queda subrayado. En el móvil, menú desplegable.
- Instalación local: enlace simbólico de esta carpeta en `wp-content/themes/uno-roto` y activar.
